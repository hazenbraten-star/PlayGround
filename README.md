## Merge &amp; Fall

A complete, dependency-free browser merge game. Reconstruct three dictatorships through 18 tiers each, train fragments with ink, survive periodic historical interludes, and merge two Tier 18 **Downfall** records to topple each regime.

- Enter from the title screen with **Start**.
- Merge identical regime/tier fragments by tapping one then its twin, or dragging one onto the other.
- **Train** a selected fragment to raise it one tier.
- **Merge All** clears every available pair; **interludes** arrive every 70–110 seconds.
- Progress saves automatically in `localStorage`.

The game is a work of satire and historical critique. It names perpetrators of mass atrocities and does not glorify them; historical notes and a content warning are included.

```bash
./start.sh          # serve the static game
./capture.sh        # capture desktop and mobile screenshots
```
